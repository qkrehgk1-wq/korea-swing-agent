# Billionaire Core v1 — 통합 전략 명세

## 목적

기존의 기술적 스크리너, Signal Council, 기술적 컨플루언스, Stoch–ADX–ATR 백테스트, 진화 학습, 기대값·리스크 예산, 라이브 추천 저널을 하나의 검증 가능한 전략 계층으로 통합한다.

이 전략은 매수 지시가 아니라 후보 선별·위험 관리 엔진이다. 실현 기대값이 양수가 되기 전에는 자동 실행과 사이징을 허용하지 않는다.

## 기존 자산 분류

| 분류        | 채택한 요소                                             | 사용 방식                           |
| ----------- | ------------------------------------------------------- | ----------------------------------- |
| 핵심 신호   | 지수 대비 상대강도, 20/60일선 정렬, ADX, MACD, 거래량비 | 과거·현재 공통 신호 점수            |
| 진입 형태   | 20일선 눌림목, 거래량 동반 돌파                         | 둘 중 하나만 충족                   |
| 보조 확인   | Stochastic K/D 교차, 누적 거래흐름, VCP·피보나치        | 점수 보강 또는 후보 변형 검증       |
| 손실 관리   | ATR 손절, 최대 위험폭, 2.5R 목표, 손익보호·트레일링     | 모든 체결에 동일 적용               |
| 시장 필터   | KOSPI/KOSDAQ 또는 SPY 벤치마크 레짐                     | 약세·데이터 불량 시 승인 축소/중단  |
| 설명 레이어 | 패턴, Elliott/Fractal, Dante 학습, 회사 정보            | 점수 가산보다 찬반 논거·경고로 사용 |
| 제외        | 미래 시점의 뉴스·펀더멘털, 사후 LLM 판단                | 역사적 백테스트 신호에서 제외       |

## 통합 의사결정 순서

1. 데이터 무결성: 벤치마크 존재, 최소 봉 수, 중복 날짜 0, 최근 시세 지연 여부 확인.
2. 시장 레짐: 벤치마크의 종가/20일선/60일선/20일 수익률/RSI로 강세·중립·약세를 계산.
3. 리더십: 종목의 60일 상대강도 0 이상, 종가 > 20일선 > 60일선인지 확인.
4. 신호 품질: ADX 20 이상, 거래량비 0.8 이상, RSI 75 이하, 20일 연환산 변동성 55% 이하.
5. 진입: 20일선 근처 눌림목 또는 거래량 1.35배 이상 돌파만 허용. 20일선 대비 15% 이상 과확장된 추격은 차단.
6. 실행 계획: 진입 트리거, ATR 기반 손절, 2.5R 목표, 0.6R 이후 손익보호·트레일링을 동시에 산출.
7. 실현성과 게이트: 라이브 저널의 R 기대값이 양수이고 표본이 충분할 때만 제한적 승격. 그 전에는 섀도 후보로만 기록.

## 현재 증거와 판단

- 한국 기존 백테스트(동적 유니버스 재생 보정 후): 11체결, 승률 72.7%, 평균 +6.60%; OOS 5체결, 승률 60.0%, 평균 +3.41%.
- 기존에 보고된 49체결 수치는 라이브의 동적 유니버스와 달리 고정 30종목만 재생한 결과였으므로 기준선에서 제외한다.
- 한국 라이브 저널: 38정산, 승률 26.3%, 평균 -5.06%; 종목 중복을 제거하면 승률 18.2%, 평균 -9.82%.
- 미국 Alpaca 기준 Stoch–ADX–ATR: 34체결, OOS 14체결, OOS 평균 +1.21%.
- Billionaire Core v1 섀도 백테스트: KRX 6체결로 표본 부족, 미국 105체결·OOS 42체결·OOS 평균 -0.01%.
- Stochastic 눌림목 강제 변형은 미국 OOS +1.20%였지만 OOS 12체결, KRX 2체결로 공통 전략 승격 기준을 충족하지 못했다.

결론: 구조는 채택하되 현재 버전은 `shadow_only`다. 기존 라이브 전략을 자동 대체하지 않는다.

## 운영 규칙

- 뉴스·수급·회사정보는 기술점수를 올리지 않는다. 부정 정보는 보류·위험 경고로만 남긴다.
- KOSDAQ 전용팀은 보조 연구 트랙이다. 핵심 기술전략 후보 및 핵심 저널과 섞지 않는다.
- 백테스트는 실제로 수집된 동적 유니버스를 그대로 재생한다. 고정 30종목으로 축소하지 않는다.
- 자동 진화 승격은 백테스트 개선만으로 충분하지 않다. 라이브 기대값, OOS 거래 수, 평균수익률, PF, 데이터 정합성을 함께 통과해야 한다.
- 기대값이 음수이거나 판정 표본이 부족하면 리스크 예산은 0%다.

## 승격 게이트

후보 전략은 다음 조건을 모두 통과해야 한다.

- OOS 체결 20건 이상
- OOS 기대값 > 0.10R
- OOS 평균수익률 > 0
- IS 대비 OOS 성과 붕괴 없음
- PF가 기준 전략보다 하락하지 않음
- 라이브 정산 20건 이상이며 기대값이 음수가 아님
- 동일한 후보 생성·청산·비용 규칙으로 라이브 저널과 백테스트가 기록됨

현재는 라이브 기대값 -0.391R/거래라 이 게이트를 통과하지 못한다.
